# court_lighting - 场馆灯光评估

拍一张场馆照片，自动分析灯光是否适合打羽毛球。

## 功能

| 指标 | 说明 | BWF 参考 |
|------|------|---------|
| 平均亮度 | 图片整体亮度 | 国际赛 500+ lux，训练 200+ lux |
| 亮度均匀度 | 亮度分布是否均匀 | 均匀度 > 0.5 为良好 |
| 眩光检测 | 高光区域 | 眩光比例 < 1% 为理想 |
| 结论与建议 | 自动给出改进建议 | - |

## 用法

```bash
# 基本用法
python -m court_lighting.analyze --image court_photo.jpg

# 指定区域分析（跳过看台区域）
python -m court_lighting.analyze --image court_photo.jpg --roi 100,100,800,400
```

## BWF 照度标准

| 级别 | 照度(lux) | 对应灰度值(约) |
|------|----------|---------------|
| 国际电视转播赛 | 500+ | 180+ |
| 一般比赛 | 300-500 | 120-180 |
| 训练/休闲 | 200-300 | 80-120 |
| 不足 | <200 | <80 |

> 注：照片灰度值与实际 lux 并非线性关系，本工具给出的是相对评估。精确测量需要用照度计。

## 原理

1. 图片转灰度图
2. 计算平均亮度（`numpy.mean`）
3. 计算均匀度 = 1 - std/mean
4. 眩光检测：阈值二值化 + 连通域计数
5. 对照 BWF 标准给出结论

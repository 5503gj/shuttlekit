# BWF 羽毛球场地与设施标准

本文档整理了世界羽联（BWF）对羽毛球场地和设施的标准，ShuttleKit 各模块的判断依据均来源于此。

## 1. 场地尺寸

| 项目 | 标准 | 说明 |
|------|------|------|
| 单打场地 | 13.40m × 5.18m | 长宽比 ≈ 2.587 |
| 双打场地 | 13.40m × 6.10m | 长宽比 ≈ 2.197 |
| 场地外安全区 | 单打≥1.0m，双打≥1.46m | 球场外缘到障碍物 |
| 发球线距网 | 1.98m | 前发球线 |
| 后发球线距底线 | 0.76m | 双打发球后场 |
| 中线宽度 | 4cm | 所有场地线 |

## 2. 球网

| 项目 | 标准 |
|------|------|
| 网柱高度 | 1.55m |
| 网中心高度 | 1.524m |
| 网孔大小 | 15-20mm |
| 网宽 | 760mm |

## 3. 灯光照明与照片分析边界

照片灰度受曝光、相机和反射率影响，不能换算lux，不能证明赛事照度合规。
本项目图片模式只报告曝光/高亮分布。此前400/500lux的国际赛事表缺乏适用依据，已撤下。

BWF官方托管的Section 5.3.4（PDF页内版本2018-11-30）§5.1对应Grade 1/2最低1000lux，§5.6.1对应转播设施1500–1600lux。
这仅是带版本的参考资料，不代表所有赛事的现行唯一要求；正式测量须采用实际赛事适用版本和校准照度计，记录网格、单位、测量位置。
[官方PDF](https://system.bwfbadminton.com/documents/folder_1_81/Statutes/CHAPTER-5---TECHNICAL-REGULATIONS/Section%205.3.4%20-%20Specs%20for%20Int%27l%20Standard%20Facilities%20-2.pdf)

## 4. 地面

- 材质：木地板或合成材料（PVC）
- 颜色：深色（建议），避免反光
- 摩擦系数：适中，既防滑又不卡鞋
- 平整度：3m 内高差 ≤ 3mm

## 5. 球速与温度

| 环境温度 | 推荐球速 | 球筒标记 |
|---------|---------|---------|
| 35-40°C | 76 慢速 | 绿色 |
| 25-35°C | 77 中速 | 蓝色 |
| 15-25°C | 78 快速 | 红色 |
| <15°C | 79 超快 | 不常用 |

> 以上场地/温度资料是参考，不由照片自动证明。照度与物理3D速度均需独立标定和测量。

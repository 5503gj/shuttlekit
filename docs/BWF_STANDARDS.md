# BWF 羽毛球场地与设施标准

本文档整理了世界羽联（BWF）对羽毛球场地和设施的标准，ShuttleKit 各模块的判断依据均来源于此。

## 1. 场地尺寸

| 项目 | 标准 | 说明 |
|------|------|------|
| 单打场地 | 13.40m × 5.18m | 长宽比 ≈ 2.587 |
| 双打场地 | 13.40m × 6.10m | 长宽比 ≈ 2.197 |
| 场地外安全区 | 单打≥1.0m，双打≥1.46m | 球场外缘到障碍物 |
| 发球线距网 | 1.98m | 前发球线 |
| 后发球线距底线 | 0.76m | 双打发球后场 |
| 中线宽度 | 4cm | 所有场地线 |

## 2. 球网

| 项目 | 标准 |
|------|------|
| 网柱高度 | 1.55m |
| 网中心高度 | 1.524m |
| 网孔大小 | 15-20mm |
| 网宽 | 760mm |

## 3. 灯光照明

| 级别 | 照度 (lux) | 说明 |
|------|-----------|------|
| 国际电视转播赛 | ≥ 500 | 高清转播要求 |
| 国际比赛 | ≥ 400 | 正式比赛 |
| 一般比赛 | 300-400 | 俱乐部/业余赛 |
| 训练/休闲 | 200-300 | 日常训练 |
| 灯具高度 | ≥ 7m | 距地面，避免眩光 |
| 均匀度 | ≥ 0.5 | 最低均匀度 |

## 4. 地面

- 材质：木地板或合成材料（PVC）
- 颜色：深色（建议），避免反光
- 摩擦系数：适中，既防滑又不卡鞋
- 平整度：3m 内高差 ≤ 3mm

## 5. 球速与温度

| 环境温度 | 推荐球速 | 球筒标记 |
|---------|---------|---------|
| 35-40°C | 76 慢速 | 绿色 |
| 25-35°C | 77 中速 | 蓝色 |
| 15-25°C | 78 快速 | 红色 |
| <15°C | 79 超快 | 不常用 |

> 注：ShuttleKit 的灯光分析模块基于照片灰度值估算照度，实际精确测量需要专业照度计。

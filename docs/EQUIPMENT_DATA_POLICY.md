# 装备数据来源与更新方案

## 结论

ShuttleKit 不绕过中羽在线、淘宝、京东等站点的验证码、登录限制、频控或访问控制。当前装备库是一个带来源标注的样本库，优先保证可解释、可复现和合规。

## 推荐的数据来源层级

1. 品牌官网或品牌授权经销商：型号、重量、平衡点、中杆硬度、官方建议零售价。
2. 京东联盟、淘宝开放平台等官方开放接口：在申请权限、遵守接口协议和展示要求后接入价格/商品链接。
3. 获得站点或作者授权的评测数据：保留原文链接、作者、抓取/整理日期和许可说明。
4. 用户投稿：球友提交型号、实测体验和购买渠道，进入审核队列后再进入推荐库。
5. 人工整理的公开评测：只保存必要的事实摘要和自己的结构化判断，不复制文章全文、图片或评论。

## 不能做的方式

- 不使用验证码绕过、滑块破解、代理池规避频控、盗用登录 Cookie 或伪造设备指纹。
- 不把搜索结果页或验证页当成真实商品数据。
- 不把没有价格/来源/日期的数据伪装成实时价格。

## 当前项目落地

- `equipment_kb/equipment.json`：推荐使用的结构化样本库。
- `data/parsed/`：海外评测解析结果，需二次审核后再合并。
- `data/raw_scrape/`：历史快照，只作为研究记录，不作为线上实时接口。
- `GET /api/equipment/stats`：显示样本数量和数据政策。
- `POST /api/equipment/recommend`：网站和小程序共用的推荐接口。

每条装备建议保留 `source` 字段；后续可增加 `source_url`、`collected_at`、`license`、`verified_by` 和 `price_checked_at`，让面试时能够讲清楚数据治理过程。

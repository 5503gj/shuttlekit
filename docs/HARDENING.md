## 接口与客户端

`pip install -r requirements-dev.txt` 后运行 `python -m pytest -q`。`python speed_api.py`默认回环监听，网页创建返回write_token/read_token。REST在Authorization: Bearer传令牌；WS建立后3秒内先发送`{"type":"auth","token":"..."}`，通过后才接收会话快照。读令牌不能写入/重置，其他会话不能借用；HTTP与WS更新共享广播。
网页可复制带只读令牌片段的大屏链接，片段不发给HTTP服务；持链接者可查看会话，请仅发给被授权者。令牌只保存在页面内存。小程序协议已同步，真机域名、TLS和平台许可仍需另行验证。公网创建/视频操作须配置32字符以上SHUTTLEKIT_ADMIN_TOKEN及SHUTTLEKIT_ORIGINS；未配置拒绝启动。管理员令牌不是租户认证方案，勿硬编码到公开小程序包中。

视频上传最多50MiB，接收层及分块写入双重限制；两个后台处理线程，忙碌返回429。视频最多60秒/3600帧/1080p，循环处理时间有预算；恶意编解码器隔离仍需要生产容器/独立进程与网关资源限额。

会话最多128个，闲置TTL一小时；轨迹与速度各保留最近300个样本，平均值为窗口统计。单会话最多16个WS显示/采集端。多进程/持久化/服务器重启恢复尚未实现。

YOLO要求显式本地权重，按类别及置信度过滤并保留帧号；COCO sports ball不等于已验证的羽毛球检测器。TrackNet直接说明未实现，不会假成功或自动下载。LLM顾问用候选ID结构化校验，供应商失败/超时/库外ID回退规则。只推荐标注最低价不高于硬预算的项目，缺价不推断，价区部分重叠仍需确认。来源和价格不是实时核验数据。

界面支持只读复盘、可取消请求和过期回复抑制；新点到达时保留带时间的报告快照并提示重新运行。

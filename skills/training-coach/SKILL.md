# training-coach

1. 先读 PRODUCT.md、DESIGN.md、docs/HARDENING.md。会话数据遵循当前API读写能力令牌和Origin权限，不把管理员密钥写进前端。

2. 未标定轨迹保留px/s；手动比例仍是2D投影估计。模拟数据显式标记；空样本与静止0分开，不补造物理角、照度或置信度。

3. 教练依据实际窗口数据和有限数值给练习建议，并列出依据及不足；建议不是统计结论或真实模型评测结果。

4. 轨迹回放只使用已有样本，动画可暂停并遵循减少动态效果。报告导出不包含会话能力令牌、管理员凭证和用户文件路径。

5. 验证用 python -m pytest -q 与 npm run test:browser；有模型的分支以mock验证错误回退，真实模型质量另行记录。

6. 保留50MiB上传、视频任务预算和有界会话/样本；新增原始文件留存需在产品中写清数据流。

在线版入口与构建见docs/ONLINE.md。浏览器和服务版本共用核心；修改后运行npm run test:online，保留以上在线能力边界，不把浏览器会话标成云端同步。
